# Local BM25 baseline

Run `python scripts/search_bm25.py "your question" --top-k 5` for a search, or
`python scripts/probe_bm25.py` for the eight fixed probe questions. Install the
project with `pip install -e .` first. Both commands use only the two local
retrieval JSON files; they rebuild an in-memory BM25Okapi index on each run.

General chunks are merged only when their original text strings match exactly.
Every original chunk's metadata is retained in `provenance`, including its
category, document ID, chunk ID, filename, and page. Top-level display metadata
comes from the first occurrence; provenance lists all sources. Project documents
are retained individually, even when their texts match. Inputs are never written.

Tokenization lowercases Unicode words and numbers, splitting on punctuation and
underscores. There is no stemming, stop-word removal, field weighting, query
expansion, or filtering by student/degree eligibility. Original display text is
retained. BM25Okapi uses rank-bm25 defaults (k1=1.5, b=0.75, epsilon=0.25).

Results include only items matching at least one query token, sorted by descending
score with corpus order as the tie-breaker. Matching items may have zero or
negative scores in small corpora; scores are not probabilities. Blank queries,
unknown terms, empty corpora, and nonpositive top-k return no results. Top-k above
the match count returns all matches. Probe output includes full text and provenance
in `data/processed/bm25_probe_results.json`; it is a diagnostic, not a relevance evaluation.
